## 5. Задание 1. Один файл — две среды выполнения

Файл `js/hello.js` запускается в Node.js и в браузере Google Chrome.

| Среда выполнения | Способ запуска | Результат `typeof document` |
|---|---|---|
| Node.js | `node practice-01/js/hello.js` | `"undefined"` |
| Google Chrome | `practice-01/index.html` | `"object"` |

Node.js и браузер предоставляют разные среды выполнения JavaScript. В браузере доступен объект `document`, представляющий HTML-документ. При запуске скрипта через Node.js браузерный DOM отсутствует, поэтому `typeof document` возвращает `"undefined"`.

## 6. Задание 2. Исследование типов и преобразований

В файле `js/types.js` исследуются десять выражений JavaScript.

| № | Выражение | Результат | Тип результата | Объяснение |
|---:|---|---|---|---|
| 1 | `"8" + 2` | `"82"` | `string` | При сложении строки и числа выполняется конкатенация. |
| 2 | `"8" - 2` | `6` | `number` | Оператор вычитания преобразует строку в число. |
| 3 | `Number("8") + 2` | `10` | `number` | `Number()` явно преобразует строку в число. |
| 4 | `"12" > "3"` | `false` | `boolean` | Строки сравниваются лексикографически. |
| 5 | `12 === "12"` | `false` | `boolean` | Строгое сравнение учитывает типы операндов. |
| 6 | `Number("")` | `0` | `number` | Пустая строка при числовом преобразовании становится нулём. |
| 7 | `Number("text")` | `NaN` | `number` | Текст не может быть преобразован в корректное число. |
| 8 | `Boolean("false")` | `true` | `boolean` | Любая непустая строка преобразуется в `true`. |
| 9 | `typeof null` | `"object"` | `string` | `typeof` возвращает строку; результат связан с исторической особенностью JavaScript. |
| 10 | `typeof NaN` | `"number"` | `string` | `NaN` относится к числовому типу, а `typeof` возвращает строку. |

В выражениях 9 и 10 тип результата — `string`, поскольку оператор `typeof` возвращает строковое значение.

## 7. Задание 3. Сводка выполнения задач

Файл: `js/progress.js`.

Для индивидуального варианта 12 используются `totalTasks = 12` и `completedTasks = 5`. Программа проверяет входные значения, рассчитывает количество оставшихся задач, процент выполнения и статус.

Результат для исходных данных:

```text
Всего задач: 12
Выполнено: 5
Осталось: 7
Прогресс: 41.7%
Статус: В работе
```

### Проверки

| Проверка | Входные данные | Ожидаемый результат |
|---|---|---|
| Вариант 12 | `(12, 5)` | Осталось `7`, прогресс `41.7%`, статус `В работе`. |
| Пустой список | `(0, 0)` | `Задач пока нет`. |
| Ни одна задача не выполнена | `(5, 0)` | Осталось `5`, прогресс `0.0%`, статус `Не начато`. |
| Все задачи выполнены | `(5, 5)` | Осталось `0`, прогресс `100.0%`, статус `Завершено`. |
| Выполнено больше общего количества | `(5, 6)` | Сообщение об ошибке. |
| Отрицательное количество | `(-1, 0)` | Сообщение об ошибке. |
| Дробное количество | `(5, 2.5)` | Сообщение об ошибке. |
| Строка вместо числа | `("5", 2)` | Сообщение об ошибке; преобразование строки не выполняется. |
| Превышена верхняя граница | `(1001, 0)` | Сообщение об ошибке. |
| `NaN` вместо числа | `(NaN, 0)` | Сообщение об ошибке. |

Процент выполнения рассчитывается по формуле:

```text
completedTasks / totalTasks * 100
```

Количество оставшихся задач определяется как `totalTasks - completedTasks`. Статус зависит от количества выполненных задач: `Не начато`, `В работе` или `Завершено`. Для пустого списка предусмотрена отдельная проверка, исключающая деление на ноль.

## 8. Задание 4. План выполнения задач по дням

Файл: `js/plan.js`.

Для индивидуального варианта 12 используются `totalTasks = 12`, `completedTasks = 5` и `dailyLimit = 3`. Оставшиеся задачи распределяются по дням с помощью цикла `while`. Количество задач на день не превышает установленный дневной лимит.

Результат для исходных данных:

```text
Осталось задач: 7
День 1: выполнено 3, осталось 4
День 2: выполнено 3, осталось 1
День 3: выполнено 1, осталось 0
Потребуется дней: 3
```

### Проверки

| Проверка | Входные данные | Ожидаемый результат |
|---|---|---|
| Вариант 12 | `(12, 5, 3)` | `3` дня; в последний день выполняется `1` задача. |
| Два полных дня | `(10, 4, 3)` | `2` дня, по `3` задачи в день. |
| Дневной лимит больше остатка | `(5, 3, 10)` | `1` день; выполняются `2` оставшиеся задачи. |
| Все задачи выполнены | `(5, 5, 2)` | `0` дней. |
| Задач изначально нет | `(0, 0, 2)` | `0` дней. |
| Нулевой дневной лимит | `(5, 2, 0)` | Сообщение об ошибке. |
| Дробный дневной лимит | `(5, 2, 1.5)` | Сообщение об ошибке. |
| Выполнено больше общего количества | `(5, 6, 2)` | Сообщение об ошибке. |
| Строка вместо дневного лимита | `(5, 2, "2")` | Сообщение об ошибке; преобразование строки не выполняется. |
| Дневной лимит выше максимума | `(5, 2, 1001)` | Сообщение об ошибке. |

Цикл `while` выполняется, пока остаются невыполненные задачи. На каждой итерации увеличивается номер дня, определяется количество задач на текущий день и пересчитывается остаток. Последний день может содержать меньше задач, чем установленный дневной лимит.

## 9. Задание 5. Поиск и исправление логических ошибок

Файл: `js/debug.js`.

В исходном варианте программы присутствовали две логические ошибки.

1. Строковые значения `completedText` и `additionalText` складывались оператором `+` без предварительного преобразования в числа. В результате вместо арифметической суммы `5` получалась строка `"32"`.
2. Условие цикла `taskNumber < 4` не включало значение `4`, поэтому контрольная сумма вычислялась только для чисел `1`, `2` и `3`.

### Результат до исправления

Для значений `plannedText = "8"`, `completedText = "3"` и `additionalText = "2"`:

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

### Исправление

Для арифметических операций строки преобразуются в числа с помощью унарного оператора `+`:

```js
const completedTotal = +completedText + +additionalText;
const remainingTasks = +plannedText - completedTotal;
```

Граница цикла изменена на `taskNumber <= 4`, чтобы в вычисление включалось значение `4`.

### Результат после исправления

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

| Ошибка | Причина | Исправление | Результат |
|---|---|---|---|
| Вместо суммы `5` получалось `32` | Оператор `+` объединял строки. | Преобразование строк в числа перед сложением. | Выполнено `5`, осталось `3`. |
| Контрольная сумма равнялась `6` | Условие `taskNumber < 4` исключало число `4`. | Замена условия на `taskNumber <= 4`. | Контрольная сумма `10`. |
